## Busca la versión oficial {#get-release}

CloakView requiere macOS 14.2 o posterior. El repositorio de GitHub y las descargas firmadas **todavía no están publicados**; la [página de descarga](/es/download) mostrará disponibilidad y hashes cuando existan. No descargues archivos de fuentes no oficiales.

## Mueve la app a Aplicaciones {#applications}

Cuando haya una versión verificada, abre el DMG descargado, arrastra CloakView a **Aplicaciones** y expulsa el DMG. Conserva el original hasta confirmar que la app abre. La página de la versión indicará las arquitecturas compatibles; las opciones Intel y Windows pendientes no son descargas disponibles.

## Primer arranque {#first-launch}

Abre CloakView desde Aplicaciones. macOS puede pedirte confirmar la apertura de una app descargada de internet. Verifica la firma y la procedencia antes de continuar; no omitas Gatekeeper para una compilación sin verificar. Añade tu propia clave de API en Ajustes y concede los permisos del siguiente artículo. Hasta que se publique una versión, estos pasos son orientativos.
