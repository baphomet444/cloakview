## Busca la versión oficial {#get-release}

CloakView requiere macOS 14.2 o posterior en un Mac con Apple Silicon. Consíguela en la [página de descarga](/es/download), que enlaza la versión oficial en GitHub y muestra su hash SHA-256. No descargues archivos de fuentes no oficiales.

## Mueve la app a Aplicaciones {#applications}

Abre el DMG descargado, arrastra CloakView a **Aplicaciones** y expulsa el DMG. Conserva el original hasta confirmar que la app abre. No hay versión para Intel ni para Windows: la página de descarga las lista solo para indicar que no están disponibles.

## Primer arranque {#first-launch}

Abre CloakView desde Aplicaciones. macOS puede pedirte confirmar la apertura de una app descargada de internet. Verifica la firma y la procedencia antes de continuar; no omitas Gatekeeper para una compilación sin verificar. Añade tu propia clave de API en Ajustes y concede los permisos del siguiente artículo.
