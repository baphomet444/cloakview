## Get the right release {#get-release}

CloakView requires macOS 14.2 or later and a Mac with Apple Silicon. The signed DMG is published on [GitHub Releases](https://github.com/baphomet444/cloakview/releases), and the [download page](/download) lists the current build with its SHA-256. Do not download a file claiming to be CloakView from an unofficial mirror.

## Move it to Applications {#applications}

Open the downloaded DMG, drag CloakView into **Applications**, then eject the DMG. Keep the original DMG until you have confirmed the app opens. Version 0.3.2 is arm64 only: there is no Intel build, no Windows version, and no installer — the DMG is the whole distribution.

## First launch {#first-launch}

Open CloakView from Applications. macOS may ask you to confirm opening an app downloaded from the internet; the build is signed and notarized, so the Open button is enough. Add your own OpenAI API key in the app's Settings and save it, then grant the permissions described in the next article.
