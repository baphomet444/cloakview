## Get the right release {#get-release}

CloakView requires macOS 14.2 or later. The GitHub repository and signed downloads are **not published yet**; the [download page](/download) shows availability and checksums when they exist. Do not download a file claiming to be CloakView from an unofficial mirror.

## Move it to Applications {#applications}

When a verified release is available, open the downloaded DMG, drag CloakView into **Applications**, then eject the DMG. Keep the original DMG until you have confirmed the app opens. The release page will identify supported Mac architectures; do not use the Intel or Windows placeholders as if they were available.

## First launch {#first-launch}

Open CloakView from Applications. macOS may ask you to confirm opening an app downloaded from the internet. Verify its signature and release source before proceeding; do not bypass Gatekeeper for an unverified build. Add your own API key in the app’s Settings, then grant the permissions described in the next article. Until a release is published, these steps are a preview, not a working download.
