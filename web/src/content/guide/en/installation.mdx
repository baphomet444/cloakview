## Get the right release {#get-release}

CloakView requires macOS 14.2 or later on a Mac with Apple Silicon. Get it from the [download page](/download), which links to the official GitHub release and shows its SHA-256 checksum. Do not download a file claiming to be CloakView from an unofficial mirror.

## Move it to Applications {#applications}

Open the downloaded DMG, drag CloakView into **Applications**, then eject the DMG. Keep the original DMG until you have confirmed the app opens. There is no Intel or Windows build: the download page lists them only to show that they are not available.

## First launch {#first-launch}

Open CloakView from Applications. macOS may ask you to confirm opening an app downloaded from the internet. Verify its signature and release source before proceeding; do not bypass Gatekeeper for an unverified build. Add your own API key in the app’s Settings, then grant the permissions described in the next article.
