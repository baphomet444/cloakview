## Available actions {#actions}

CloakView has global shortcuts for **quick hide** (show or hide the private overlay), **push-to-ask** (show the Ask window, bringing the hub back if it was hidden), **start/stop listen**, and **read screen**. You can use them while another app is focused. These controls do not join or modify your call.

## Configure your keys {#configure}

The defaults are Option–Shift–H (quick hide), Command–Shift–Space (push-to-ask), Option–Shift–L (start/stop listen) and Command–Shift–S (read screen). Quick hide and listen avoid Command–Shift–H and Command–Shift–L, which Finder and Safari use. Change them in **CloakView → Settings → Shortcuts**. Choose combinations that do not conflict with your meeting app or macOS. Save changes and test each action in a harmless window.

## If a shortcut does nothing {#conflicts}

Try its button in the app first. If another app already holds the combination, the hub shows an error when CloakView starts or when you save your shortcuts; change it in CloakView Settings or the other app. Shortcuts that use only Option and Shift (such as the defaults for quick hide and listen) don't work while macOS secure input is on — for example in Terminal with Secure Keyboard Entry, or while a password field is focused; Command shortcuts still do. If the shortcut starts listening, check capture and microphone permissions, plus your API key, before testing again. A hidden hub is not proof that capture stopped: use **Stop Listen** to end capture.
